はじめての方へ — 操作ガイド
  1. プロフィール: User ID はブラウザに自動保存される UUID です(API の X-User-Id ヘッダに使用)。Display Name はチャットに表示される名前です。
  2. 会話を作成: 左パネルの「新規会話」フォームにタイトルを入力して作成します。
  3. 会話を選択: 一覧から会話をクリックすると右側にメッセージが表示されます。
  4. メッセージを送信: 下部の入力欄に本文を入れて送信します(Enter で送信 / Shift+Enter で改行)。初回送信時は自動的に参加(POST /conversations/{id}/participants)します。
  5. API 仕様の詳細は右上の Swagger UI を参照してください。
